# رَتّب — تطبيق أندرويد عربي

نسخة Android أصلية أولية بواجهة عربية داكنة، تضيف المهام وتضبط تنبيهًا لكل مهمة، مع تكرار يومي/أسبوعي وتخزين محلي وإعادة جدولة بعد إعادة تشغيل الهاتف.

## بناء APK
هذا المجلد **مشروع مصدر** وليس ملف APK جاهزًا؛ بيئة الإنشاء الحالية لا تحتوي على Android SDK/Gradle لإنتاج APK واختباره مباشرة.

### أسهل طريقة باستخدام GitHub Actions
1. أنشئ مستودعًا خاصًا أو عامًا على GitHub وارفع محتويات هذا المجلد إليه.
2. افتح تبويب **Actions** واسمح بتشغيل workflows إذا طلب GitHub ذلك.
3. شغّل workflow المسمى **Build Android APK**.
4. بعد اكتمال البناء، افتح تشغيل الـ workflow وحمّل artifact المسمى `rattib-debug-apk`.
5. انقل `app-debug.apk` إلى جوالك وافتحه، ثم اسمح بالتثبيت من هذا المصدر عند الطلب.

أو افتح المشروع في Android Studio واضغط Build > Build APK(s).

## ملاحظات مهمة
- أول تشغيل يحتاج السماح بالإشعارات. على Android 12+ قد تحتاج أيضًا السماح بالمنبهات الدقيقة من إعدادات النظام.
- وضع توفير البطارية/الشركة المصنّعة قد يؤثر على توقيت التنبيه؛ اختبره قبل الاعتماد عليه لمواعيد مهمة.
- هذه نسخة أولية؛ لا تتضمن مزامنة سحابية، والمهام محفوظة على الجهاز.
